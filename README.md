# Planet F

Downloads for **Planet F**, a game by Jay Randolph. Each version is a [GitHub release](https://github.com/jameshrandolphv/planet-f-release/releases) tagged with its version number. The same downloads are listed on [jayrandolph.com](https://jayrandolph.com/desktop-apps/planet-f), under Desktop Apps > Planet F.

## Latest: alpha-1.1.0

| Platform | Download | Requires |
| --- | --- | --- |
| Windows | [Planet.F.exe](https://github.com/jameshrandolphv/planet-f-release/releases/download/alpha-1.1.0/Planet.F.exe) | 64-bit Windows |
| Mac | [Planet.F.zip](https://github.com/jameshrandolphv/planet-f-release/releases/download/alpha-1.1.0/Planet.F.zip) | macOS 12 Monterey or later |

This is an alpha, so expect rough edges.

## Installing

**Windows:** download `Planet.F.exe` and run it. If Windows SmartScreen says it protected your PC, click **More info**, then **Run anyway**.

**Mac:** download `Planet.F.zip` and open it to unzip `Planet F.app`, then drag the app into your **Applications** folder and open it. If macOS says it can't check the app for malicious software, right-click the app and choose **Open**, or allow it under **System Settings > Privacy & Security**.
